# MO QR

موقع MODEGLI لتحويل الصور إلى QR Code.

## قبل النشر
هذه النسخة تستخدم ImgBB لرفع الصورة ثم تنشئ QR للرابط العام.

1. أنشئ API Key من ImgBB.
2. افتح `script.js`.
3. ابحث عن:
   `YOUR_IMGBB_API_KEY`
4. استبدله بمفتاحك.
5. ارفع `index.html` و`style.css` و`script.js` إلى مستودع GitHub.
6. فعّل GitHub Pages من Settings → Pages → Deploy from branch.

ملاحظة: لا ترفع صورًا خاصة أو حساسة، لأن الصورة تصبح مستضافة على خدمة رفع عامة.
